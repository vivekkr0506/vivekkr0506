## 🧠 Engineering Principles

> **Build for the real world, not just the happy path.**

- Keep architecture simple and maintainable.
- Prefer a reliable local source of truth for offline-first experiences.
- Keep business logic independent from UI.
- Measure performance instead of guessing.
- Design for network failures.
- Automate repetitive release processes.
- Make production issues observable and debuggable.
- Ship small, reliable changes.
